Please note the following:

Use the "Submit Notification" button to notify EH&E staff once {{pws.pwsid}} is ready to file a Supplemental Fund Claim for a given source. This would occur when:

  1. A source was "unimpacted" (i.e., there was no measureable concentration of PFAS detected in the water source) at the time of filing the action fund claim but has since exhibited detections of PFAS; OR

  2. A source exhibited PFAS detections below the Proposed Federal PFAS MCLs or applicable State PFAS MCLs at the time of filing the action fund claim, but have since had one or more PFAS detections above the Proposed Federal PFAS MCLs or applicable State PFAS MCLs.

Note that, based on the above, there are a maximum of two (2) opportunities for a PWS to submit a Supplemental Fund Claim for a source that was "unimpacted" at the time of filing the original Action Fund claim. Please refer to our Supplemental Fund Helpful Information page for more details on this, in addition to the general requirements of the Supplemental Claims process.

Data Dictionary:

Source Name: The name of the source.

Instance: A reference to whether the record is the first or second supplemental fund claim that can be filed for a given source. This field takes a value of "---" if the source cannot file a claim at all, a value of "First Claim" if it's the first claim that can be filed for a given source, and a value of "Second Claim" if a source had already filed it's first supplemental claim and is eligible to file another.

Source Status: What the status of the source is relative to the potential claim that can be filed. If a source cannot file a claim at all, this field takes a value of "Unable to File a Claim". If a source has the potential to file a claim

Submit Notification to Proceed: When the water provider has received PFAS results that either exhibits any PFAS detection or exhibits a PFAS detection above MCLs (see "Source Status" field for what is applicable), click this button to start the process of notifying EH&E about preparing the Supplemental Claim.

Claim Status: The status of the claim. This field takes the following values:

  • "Claim Submitted" if the claim has been submitted
  • "Claim Under Review" if the PWS has initiated contact with EH&E about filing a Supplemental Claim for the source
  • "Claim Not Filed" if a claim has not yet been filed for the source and the PWS has not initiated contact with EH&E about filing a claim (e.g., because PFAS results currently do not warrant a claim)
  • "---" if the source cannot file a claim at all

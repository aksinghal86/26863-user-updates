Important Information

This Public Water System Dashboard contains your claims data for {{ pwsid }} used in submitting previous settlement claims under 3M, DuPont, Tyco, and/or BASF, as applicable. More specifically, the table below shows:

  • Whether a source is impacted by PFAS
  • The maximum PFAS results for each source
  • The maximum annual production (shown in MGY) for each source
  • The maximum flow rate (shown in GPM) for each source
We will use this data for the new Settlements with Carrier, Archroma, Amerex, and Nation Ford (“CAAN Settlements”). If you wish, you may update your source data using this portal. We recommend the following types of source updates:

  • Provide higher PFAS results if you have any.
  • Provide any missing annual production years (We can submit years 2013 – 2025 in these new settlements).
  • Provide details on any new water sources not previously submitted.
Hover over any of the PFAS Results, Average Annual Flow, or Max Flow values to provide updates for EH&E’s review. If a row in the table contains a warning symbol ( ), this indicates that more information may be required and should be reviewed. For example, if the warning symbol appears in the "Average Annual Production (MGY)" column, this means that the source is impacted and that there are less than three years of non-zero annual production. Please provide annual production (if it exists). If the warning symbol appears in the "Maximum Annual Production (MGY)" column, this means that the source is impacted but the maximum flow rate is listed as zero. Please provide a maximum flow rate.
